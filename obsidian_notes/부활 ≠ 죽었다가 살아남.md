23/12/20 <부활 ≠ 죽었다가 살아남> 구절정리

  

■부활의 성경적 의미

부활, 죽었다가 살아났다는 뜻 아님

  

히브리서 11:35

_죽었던 자가 살아나는 것은; '살아났다, 돌아왔다'고 함. 

_성경 전체에서 죽었던 사람이 살아나는 것을 부활이라고 하는 경우 없음

_부활은 그것보다 더 좋은 것

  

고전 15:12~13

_부활의 핵심은 상태가 바뀌는 것; 그 중에서도 몸

_성경에서 말하는 부활은 몸이 바뀌는 것

  

고전 15:35

_죽은 자들이 다른 몸으로 오는 것을 부활이라고 함

  

고전 15:42 / [판서]

_썩는다 corruptable = 유한하다 / 썩지 않는다 incorruptable = 영원하다

_영원한 몸으로 바뀌는 것이 부활

  

고전 15:44

_영적인 몸 spiritual body; 나중에 바뀌는 몸은 영과 같은 편

_죄를 짓지 않는 몸 = 죽지 않는 몸

  

고전 15:51~57

_썩지 않음, 죽지 않음; 나중에 입을 몸은 이 두가지 측면을 다 갖고 있음

  

  

■최초의 부활 

사도행전 26:23

_최초의 부활; 예수님

_인간 역사 상 현재까지 유일한 부활

  

로마서 8:3

_아들 하나님이 이 땅에 예수로 오심

_likeness of sinful flesh; 우리 같은 몸; 죄의 충동들이 나오는 몸으로 오심

_화목제물/속죄제물 되시려면 우리와 똑같은 상태에서 죄를 짓지 않으셔야 함; 

_죄의 충동과 아버지 하나님의 말씀 중에 계속 선택을 하셔야 했던 것

  

빌립보서 2:5~8

_이 땅에 예수로 오시기 전, 아들 하나님의 몸은 죄의 충동이 없는 몸

_빛 재질 예수님; 재질은 우리와 다르지만, 충동은 우리와 같은 몸

_순종; 이 땅에 오셨을 때 시작해서, 십자가에 죽음까지. 십자가에서 다 이루셨다로 끝; 

  

부활하셨을 때는 죄의 충동이 없는 몸으로 바뀌셨음

_그래서 예수님이 부활하셨다고 하는 것

  

  

■저주 받은 몸

로마서 7:14~25

_우리의 문제는 몸; 그냥 몸이 문제인 것

  

창세기 2:17

_죽으리라; 우리가 생각하는 죽음은 일어나지 않았으나,

  

창세기 3:17

_선악과를 먹은 결과; 땅이 저주 받음 = 몸이 저주 받음

_가시나무와 엉겅퀴; 죄의 충동이 몸에서 마구 나옴

  

  

■3가지 부활

데살로니가전서 4:14~17

_교회가 완성이 되면; 거듭난 사람들 중에 죽어있는 사람들이 먼저 낙원에서 영혼이 돌아와 흙의 몸이 살아나고 하늘 재질의 몸으로 삼켜지고. 살아있는 사람들은 몸만 바뀜; 그것을 부활이라고 함

  

고린도전서 15:22~26

_인간이 부활하는 날 딱 3번; 이 중에 언제 부활하는가가 관건

_①우리시대 거듭난 성도들의 부활 / ②환란성도들, 구약 의인들 / ③나머지 사람들 

_<MILK 9. 부활과 심판>

  

  

■ (우리 시대) 거듭난 성도들의 부활 = 소망

로마서 8:23,29

_부활 때 몸이 바뀌면, 입양이 됨

_거듭나면, 입양이 확정되었기 때문에 하나님의 자녀라고 하는 것

_종이 다르면 결혼이 되지 않으므로; 부활해서 몸이 바뀌면 결혼해서 아내가 됨

(⇒<하나님의 어음은 현금(23/07/16)> 참고)

  

  

■저주의 부활

_거듭나지 않은 사람들은 영원한 몸으로 바뀌어서 불연못에 가는데, 그것도 부활이라고 함

  

요한복음 5:27~29 / 사도행전 24:15

_태어난 이상, 우리가 생각하는 죽음은 없음.

영원히 사는데; 어디에서 사는가, 어디를 가는가의 문제

_전도를 간절한 마음을 갖고 해야하는 이유가 여기에 있음

  

  

■부활 + 심판 | <MILK 9. 부활과 심판> 참고

_부활은 무조건 심판을 동반함

_각각 부활하는 시기와 장소가 다르고 부활하는 순간 받는 심판의 종류도 다름

  

그리스도의 심판석; 지체들만 모아놓고 따로 심판; 

_지옥에 가는 정죄 없고 칭찬과 책망만 있음; 누구나 칭찬을 받으나 그 범위만 정해짐

  

  

■부활을 미리 경험

빌립보서 3:7~21

_사는 동안 그리스도의 지체로 살면 그런 경험을 할 수 있다 = 죄를 안 짓는 몸의 상태를 순간순간 경험

_부활이 보장된 사람 답게 살아보려고 애쓴다 = 육신의 소욕을 이길 수 있다

_미리 그렇게 살아볼 수 있다
